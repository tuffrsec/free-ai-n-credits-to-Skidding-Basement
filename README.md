# free-ai-n-credits-to-Skidding-Basement
Free ai (FA) is an open-source, AGPL-v3 licensed Python tool that acts as a local proxy wrapper. It allows you to route 12 different AI coding assistants (like Claude Code, Codex, and Aider) through 61 different AI providers (including Nvidia NIM, Gemini, DeepSeek, and free tiers) with built-in token optimization and fallback reliability.

🚀 Quick Start

1. Install:
	• macOS/Linux: curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh
	• Windows: & ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))
2. Start the Server: Open the desktop app or run fcc-server in your terminal. This launches the web-based Admin UI.
3. Add a Provider: Go to the Admin UI, select a provider (like NVIDIA NIM or Gemini), add your API key, choose your model, and click Apply.
4. Run Your Agent: Launch your desired agent using its FCC terminal command:
	• Claude Code: fcc-claude
	• Codex: fcc-codex
	• OpenCode 2: fcc-opencode
	• Cline: fcc-cline / Aider: fcc-aider

🔌 Editor & App Integrations

To use FCC inside your IDE or desktop applications, open Admin UI → Integrations and click Connect on the corresponding card:
• VS Code / VS Code Chat: Connect and select an FCC model in the native picker.
• Claude Desktop / DeepSeek Harness: Quit the app fully, connect via FCC, and reopen.
• JetBrains: Connect via FCC, restart the IDE, and choose the Claude Code (FCC) agent.
• Other Clients: Point your client's OpenAI-compatible base URL to http://127.0.0.1:8082/v1.

💬 Messaging Integrations (Discord & Telegram)

You can link FCC to Discord or Telegram bots via Admin UI → Messaging.
• Supports Voice Notes transcription using local Whisper or NVIDIA NIM.
• Commands: /stats (session status), /stop (cancel work), and /clear (wipe chat history).

🛠️ Maintenance & Lifecycle Commands

• Check Version: fcc-server --version
• Run Diagnostics: fcc-doctor (use this output for bug reports)
• Update: Stop all FCC instances and run fcc-update
• Uninstall: Stop all commands and running clients, then run:
